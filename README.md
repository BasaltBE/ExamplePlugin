# ExamplePlugin

Build this plugin from the Basalt repository with:

```sh
basalt plugin build
```

The command accepts these options:

```text
basalt plugin build [--project <file>] [--output <directory>] [--runtime <rid>] [--no-restore]
```

For example, to select the project and output directory:

```sh
basalt plugin build --project ExamplePlugin.csproj --output publish
```
